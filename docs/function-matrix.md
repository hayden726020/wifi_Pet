- 阶段 1：显示/按键原型完成并实机验收。

- 阶段 3：本地 HTTP 协议与 Companion 页面部署完成；2026-11-11 手机视觉及喂食/玩耍/摸摸/睡觉触控验收通过。Android App 与长连接未开始，按后续产品需求决定。
